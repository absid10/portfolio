# Changelog

All notable changes to the Abdullah Ahmed Siddiqui Portfolio will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.2.1] - 2026-09-04

### Added
- Schema.org JSON-LD Person and CollectionPage structured data for rich search engine result snippets.
- Accessibility media queries (`prefers-reduced-motion`) and scroll behavior hardening.
- Automated timeout and network error recovery for contribution matrix script.

## [1.2.0] - 2026-09-02

### Added
- Dedicated `/resume` route with clean URL rewrite and custom OpenGraph metadata.
- PWA `site.webmanifest` and SEO XML sitemap with crawler directives.
- Production cache-control and browser security headers via Vercel edge configuration.

### Improved
- GSAP ScrollSmoother integration across `projects.html` with card entrance choreography.
- Restructured footer navigation links into a balanced 3x2 responsive grid.
- Preloader lifecycle and curtain animation synchronization.

## [1.1.0] - 2026-08-25

### Added
- In-page Google Drive PDF resume viewer with instant modal controls.
- Ranked projects catalogue (`projects.html`) with live deployment badges.
- Dynamic GitHub contribution heatmap generation workflow.

### Fixed
- Stacking context and pointer-event interception on fixed header during page landing.
- Offcanvas navigation backdrop visibility on mobile viewports.

## [1.0.0] - 2026-08-15

### Added
- Initial production release of modern developer portfolio.
- Dark mode glassmorphism UI with custom accent theme (`#E8553A`).
- Interactive skills showcase, work experience timeline, and contact form.
